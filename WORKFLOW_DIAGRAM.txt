KEY FEATURES:

📍 GPS Location Detection
   • "Use My Location" button
   • Browser Geolocation API
   • Blue device marker vs. green farm markers
   • ±50-100m accuracy typical
   • Error handling & manual fallback

🌱 Farmer-Friendly Crop Selection
   • 20 crops from FAO-56 database
   • Full names: "Corn (Maize, Field)"
   • Categories: Grains, Legumes, Vegetables, Cover Crops
   • Scientific parameters preserved (Kc, rooting depth)

📅 Accessible Date Picker
   • "When do you want to plant?"
   • HTML5 date input (native on mobile)
   • Validates against past dates
   • Timezone-aware

🔬 Science-Based Assessment
   • NASA POWER 3-year historical climate
   • FAO-56 crop water requirement model
   • Temperature suitability by crop category
   • Irrigation need estimation
   • No fabricated scores or yield predictions

📊 Explainable Results
   • Clear recommendation (Recommended/Caution/Not Recommended)
   • Climate evidence from NASA POWER
   • Risks and uncertainties
   • Practical farmer actions
   • Full data source attribution

📡 Hardware Integration
   • LOLIN NodeMCU V3 / ESP8266 support
   • DHT11, soil moisture, water level sensors
   • Real telemetry distinguished from demo mode
   • Current conditions as context (not validation)
   • Works offline if hardware unavailable

🔄 Rotation Comparison
   • "Compare Other Planting Plans" button
   • 3-rotation analysis preserved
   • Water stress differences
   • FlipPoint sensitivity analysis
   • Challenge objective maintained
